# Frontend Design

A Claude Code skill for creating distinctive, intentional user interfaces. It provides design guidance for choosing a visual direction, typography, color, layout, and interface details that fit the product instead of relying on generic templates.

## What this skill is for

Use this skill when:
- Building a new web interface or product experience.
- Redesigning an existing page or application.
- Establishing a visual direction for a specific audience and use case.
- Improving typography, color, spacing, composition, and visual hierarchy.
- Moving away from repetitive, template-like UI patterns.

## Usage

1. Make the skill available in your Claude Code skills configuration using the installation method supported by your Claude Code setup.
2. Invoke or reference **Frontend Design** when asking Claude Code to build or refine an interface.
3. Provide the product context, target audience, required functionality, and any design constraints. The skill is most useful when the brief explains what the interface is for, not just what components it should contain.

## Design principles covered

- Establish a visual direction grounded in the product and its audience.
- Make deliberate choices about typography, color, and layout.
- Build clear visual hierarchy and intentional composition.
- Avoid default-looking, interchangeable interface patterns.
- Make design decisions that support the brief and user experience.

For the complete instructions, examples, and constraints, read [`SKILL.md`](./SKILL.md).
